## Honest limits per repository (from each DOSSIER.md § Limits)

- **armilla-astrolabe** — no Limits section in DOSSIER.md yet
- **omni-ring** — A cue is mandatory for resonance; unguided decoding is seed-dependent and abstains when it fails. Resonant capacity ≈ 12 marks per slot at one cue (the exhaustive sift reads more). Superposition is finite: triangle buckets are safe to 256 facts; beyond that, truth must live in exact rows. Exact multi-hop lookups are ~250x faster in an indexed database (Part 2 §9).
- **vsa-core** — "Sub-nanosecond binding" was false (~35 ns). "67M ops/s" came from a degenerate benchmark. "Zero-token telemetry" is not how language models consume vectors — a projection head feeding a few slots is. Not built in 0.1.0: semantic search or routing over the bus; timing of a single published-slot read. The bus is single-machine shared memory; multi-machine use goes through omni-ring shards (Speculative at scale).
- **omniring-research** — no Limits section in DOSSIER.md yet
- **tarsus** — Preflight: an `operations` value that is a JSON *string* of an array is split into one-character bash ops; a top-level Python-dict string is rejected. The C++ interceptor's inference is not implemented; it answers with an explicit error by design. The advisory classifier does not discriminate destructive commands; it is advisory only.
- **talon** — Commander role plugins (fleet status, dispatcher queries) are not in 0.1.0; they read the original fleet's databases. Role prompts and tools are read from an OpenCode-style config; without one, roles fall back to defaults. No offline mode by design.
- **agent-reliability-kit** — `done-gate --selftest` contains cases tied to the original fleet (a `bin/done-gate` path, a local service port) and is not meaningful outside it; the behavioural tests replace it. The gate shells out to `sqlite3`; SQL inputs are task ids, quoted but not parameterised. Router thresholds (4 attempts, 24 h) are fixed constants.
- **cost-savers** — The A/B covers short, read-only sessions on one free model; long sessions and other providers are untested. `cloud-pacer` deliberately slows requests. Plugins target OpenCode's plugin hooks; other agent runners need adapters.
- **dock** — Lexical search only; no semantic matching. Not measured: catalogs above 30 tools, `search_tools` latency, clients other than opencode.
- **omnid** — Neither the bitnet.cpp tree nor any model is shipped. The memory-search, reasoning and event workers are not in this repository; without them those ops are unavailable. Web-face behaviour under load is not measured.
- **omni-render** — Three fault-localisation probes failed their bars (doc 35); the reader reads Rust and JavaScript only. Pristine fixes move boxes away from Chrome where Chrome draws the same defect. Script-heavy pages are not light (Omni Web census, doc 33).
- **omni-ui** — Not light on script-heavy pages (up to 2.23 GB on a video site). Transforms and keyframes (compositor) not built; plug-ins, developer tools, the tracker head designed only. No screen-reader session and no daily-use test recorded.
